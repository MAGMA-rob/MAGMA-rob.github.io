# Get Started

Start by running a provided example before building a scenario or integrating a custom agent system.

1. Follow the [installation guide](installation.md).
2. Configure the [generation example](../use-magma-gen/quickstart/installation.md).
3. [Launch the example](../use-magma-gen/quickstart/launch-first-generation.md) and inspect its output directory.

:::warning Example availability
The existing example still depends on the reference agent setup, which is marked as forthcoming. The installation and execution instructions are being migrated to MAGMA 1.0; this path is not yet a complete ready-to-run quickstart.
:::
